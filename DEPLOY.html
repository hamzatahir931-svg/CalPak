🚀 CalPak Deployment Guide

Get your Pakistani Calorie Tracker online in minutes

What You Have

3 simple files that make a complete PWA:

index.html (app UI + all logic) sw.js (offline support) manifest.json (PWA metadata)

No backend server required. No databases. No API keys (unless you add Google Sign-In). This is a true offline-first app that works entirely on your user's device.

✨ What Users Get

🍛
100+ Pakistani Foods
Pre-loaded: Roti, Biryani, Daal, Karahi, Samosa & more
📊
Daily Tracking
Calories, Macros (Carbs, Protein, Fat), Portion sizes
💾
Offline First
Works without internet. Data stored on device.

Install Like App
Android: Add to home screen. iOS: Add via Safari.

Privacy

🎯 Deployment Options (Pick One)

✅ RECOMMENDED: Vercel (Free, Easiest)

Optimized for static files. Free tier includes unlimited bandwidth.

1 Go to vercel.com
2 Sign up with GitHub or email
3 Click "Add New Project" → "Import Git Repository"
4 Select your repo with the 3 files
5 Click Deploy. Done! Your URL: your-project.vercel.app
Deploy to Vercel
✅ Netlify (Free)

Drag & drop deployment, very beginner-friendly.

1 Go to netlify.com
2 Sign up (free GitHub, Google, email)
3 Drag the folder with 3 files into Netlify's deploy zone
4 Done! Live instantly at random-name.netlify.app
Deploy to Netlify
GitHub Pages (Free, Ties to Repository)

Free tier at username.github.io

1 Create GitHub repo: calpak
2 Upload 3 files to main branch
3 Go to repo → Settings → Pages → Deploy from main
4 Your URL: username.github.io/calpak
Own Server / VPS (nginx, Apache, etc)

Full control. Any hosting provider works.

1 Upload 3 files to your web server's public folder
2 Ensure HTTPS is enabled (required for PWA)
3 Check MIME types are set correctly:
.html → text/html
.json → application/json
.js → application/javascript
4 Access at your domain. Done!

🔐 Optional: Google Sign-In

Skip this if you want demo mode only. For real Google login:

1 Go to Firebase Console
2 Create new project: name it "CalPak"
3 Go to Authentication → Sign-in method → Google → Enable
4 Go to Project Settings → Your apps → Add Web App
5 Copy your config values:
apiKey: "AIzaSy..."
authDomain: "your-app.firebaseapp.com"
projectId: "your-app-id"
6 Go to Settings → Authorized Domains → Add your domain
7 When users open CalPak, they'll see a Firebase setup modal. They paste the config. Done!
✅ Note: Config is saved locally on each user's device. You never see it.

📱 How Users Install

Android (Chrome / Firefox)

1 Open CalPak URL in Chrome
2 Tap ⋮ (menu) → "Install app"
3 Tap "Install"
4 CalPak appears on home screen like a normal app

iPhone (Safari)

1 Open CalPak URL in Safari
2 Tap Share → "Add to Home Screen"
3 Name it "CalPak" → Add
4 Icon appears on home screen

Desktop (Chrome, Firefox, Edge)

1 Open CalPak URL
2 Address bar shows install icon (or URL bar menu)
3 Click install → Opens as windowed app

🔧 Troubleshooting

Install button doesn't appear

✓ Must be on HTTPS (except localhost)
✓ Must access from Chrome/Firefox on Android
✓ Try closing and reopening the app
✓ Check DevTools → Application → Manifest loads correctly

Google Sign-In shows error

✓ Check Firebase config is correct
✓ Add your domain to Firebase → Settings → Authorized Domains
✓ Make sure Google auth is enabled in Firebase
✓ Try demo mode instead (no login)

Data not saving

✓ Check browser allows localStorage (Settings → Privacy)
✓ Try a different browser
✓ Clear browser cache and try again
✓ Export your data before clearing

Service Worker not registering

✓ Must be HTTPS (or localhost)
✓ Hard refresh: Ctrl+Shift+R
✓ Check DevTools → Application → Service Workers
✓ Check browser console for errors
